# Lumina Portal 🛒

A modern, fast, and responsive E-Commerce & CRM Portal built using **Next.js 15**, **Tailwind CSS**, and **MongoDB**.

## 🌟 Features Overview

- 🚀 **Next.js App Router**: High performance rendering & fast navigation.
- 🎨 **Modern Design**: Responsive UI built with Tailwind CSS & Lucide Icons.
- 🔒 **Authentication & Security**: Multi-factor authentication (2FA) & secure session handling.
- 📦 **Dynamic Product Management**: Seamless product browsing, search, and category filtering.
- 🌐 **Multi-Language Support**: Built-in language switching capability.

---

## 🛠️ Tech Stack

- **Framework:** Next.js 15 (React 19)
- **Styling:** Tailwind CSS
- **Database:** MongoDB (Mongoose)
- **Language:** TypeScript

## ⚡ Quick Start

### 1. Clone the repository
```bash
git clone https://github.com/YOUR_USERNAME/agha-crm-portal.git
cd agha-crm-portal
```

### 2. Install dependencies
```bash
npm install
```

### 3. Setup Environment Variables
Create a `.env.local` file in the root directory:
```env
MONGODB_URI=your_mongodb_connection_string
JWT_SECRET=your_secret_key
```

### 4. Run Locally
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) in your browser.
